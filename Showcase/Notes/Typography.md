#### Heading four

Body text should be comfortable to read for a long time. Use **bold** for emphasis, *italics* for titles, and `code` for things you type.

- Line length: 60–80 characters
- Line height: about 1.6
- One typeface, two or three weights

```css
body {
  --font-text-size: 16px;
  --line-height-normal: 1.6;
}
```
